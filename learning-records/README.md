# Learning records

Здесь появятся только подтверждённые знания ученика, а не журнал занятий и не тексты практики. Первый файл создаётся после реального доказательства понимания и получает имя `0001-slug.md`; следующий номер увеличивается на один.

Формат: заголовок и 1–3 предложения о том, что ученик доказал и почему это меняет следующий урок. Не записывать сюда клиентские данные, личные заметки, ответы викторин, ключи, пароли или полный Blueprint. Если понимание заменено, старый record получает `Status: superseded by LR-NNNN`.
