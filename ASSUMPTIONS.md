# Assumptions — «Роботы работают»

- Ученик может вести личные заметки, но не вставляет их в приложение.
- У владельца процесса есть право остановить пилот и принять решение по APPROVAL_REQUEST.
- Для упражнений доступны только публичные либо подготовленные данные без персональной и коммерческой тайны.
- «Агент» — рабочее определение курса, не универсальный научный консенсус.
- Повторяемость означает достижение объявленного порога на серии похожих запусков, не byte-identical ответ LLM.
- Экономический результат остаётся гипотезой, которую сравнивают с baseline по времени, стоимости, качеству и риску.
